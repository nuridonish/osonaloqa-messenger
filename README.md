## ✨ Имкониятҳо

| Бахш | Функсияҳо |
|---|---|
| 💬 **Чатҳо** | Паёмҳои онлайн ✓/✓✓ (кабуд), «менависад…», онлайн/охирин бар, навбати офлайн, ҷустуҷӯ, ситораҳо (Избранное) |
| 🖼 **Медиа** | Акс, видео, файл, 📍 геолокация, 👤 контакт, 📊 опрос (овоздиҳӣ), 📅 мероприятие, 🎤 овоз бо таймер, 🎥 видео-кружок |
| 📞 **Зангҳо** | Аудио/видео занг (WebRTC + TURN), динамик/блутуз/микрофон/сабти занг, клавиатураи занг бо контактҳои телефон, SMS |
| 👥 **Гурӯҳҳо** | Гурӯҳи нав (3 қисми интихоб), Сообщества, рассылка |
| 📱 **Занг ба ҷаҳон** | Рақамҳои ҳамаи кишварҳо (E.164), ҷустуҷӯи кишвар бо код |
| 🌍 **6 забон** | Тоҷикӣ, Ӯзбекӣ, Русӣ, Форсӣ, Англисӣ, Арабӣ (RTL) |
| ⚙️ **Танзимот** | Тема (торик/равшан), ҳуруф, огоҳиномаҳо, махфият, назорати волидайн, дастрасии махсус, дастгоҳҳои пайваст, QR, ивази аккаунт |
| 🔐 **Бехатарӣ** | Access/Refresh токенҳо, OTP, кеистори доимӣ |

## 🏗 Меъморӣ

```
osonaloqa-messenger/
├── server/    ← Node.js 20 + TypeScript + Fastify + WebSocket + SQLite
└── android/   ← Kotlin + Jetpack Compose + Material 3 + Room + WebRTC
```

- **Server**: REST `/v1/*` + WebSocket (паёмҳо, typing, presence, занг, навбати офлайн), медиа-боркунӣ, OTP (dev: `000000`)
- **Android**: minSdk 26 / target 36, MVVM, офлайн-первый (Room), авто-refresh токен, auto-reconnect WS

## 🚀 Оғози зуд

### Сервер
```bash
cd server
npm install
npm run dev        # http://localhost:8080
npm test           # 22 тест
npm run e2e        # 16/16 сабз
```
Веб-версия: `http://localhost:8080` дар браузер кушоед!

### Android
`android/` кушоед дар Android Studio → Build APK
ё тавассути **GitHub Actions**: ҳар push → APK дар Artifacts.
